# Entrepôt

Pousse les caisses sur les marques jaunes. On ne peut que pousser, jamais tirer : 12 entrepôts faits main.

Range toutes les caisses sur les marques. Le magasinier pousse une caisse en marchant contre elle, mais ne peut pas la tirer. Annuler, recommencer, 12 niveaux de plus en plus rusés.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Entrepôt → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
